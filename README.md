# SketchSync 

A multiplayer drawing and guessing game inspired by Skribbl.io.

## Features

- Create and Join Rooms
- Realtime Drawing
- Live Chat
- Word Guessing
- Scoreboard
- Timer
- Multiple Rounds
- Drawer Rotation
- Winner Announcement
- Responsive UI

## Tech Stack

### Frontend
- React
- Socket.IO Client
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- Socket.IO

## Installation

### Backend

npm install
npm run dev

### Frontend

npm install
npm run dev
